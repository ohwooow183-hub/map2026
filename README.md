# ROSREESTR TO COORDINATE

![PyPI](https://img.shields.io/pypi/v/rosreestr2coord?style=flat-square)

⚠️ **ВНИМАНИЕ**: Данная версия использует новое API (НСПД вместо ППК).
Обратите внимание, что коды типы площадей были существенно изменены – ознакомитесь с описанием параметров командной строки ниже.
Версии библиотеки rosreestr2coord 4 и ниже больше не поддерживаются!

Инструмент, позволяющий вычислять координаты участка по его кадастровому номеру.
Данные берутся с Геоинформационного портала НСПД [https://nspd.gov.ru/map](http://pkk.rosreestr.ru/).

Результат работы скрипта **не соответствует информации в кадастровой выписке**

**Удобно получать данные прямо в QGIS можно с помощью [вот этого инструмента](https://nextgis.ru/blog/ngq-rr/)** (нужна подписка)

![Plot output](https://raw.githubusercontent.com/rendrom/rosreestr2coord/master/images/plot_example.png)

## Зависимости

- Python >= 3.6

## Установка

### Для использования (Production)

Для установки стабильной версии пакета используйте `pip`:

```bash
pip install rosreestr2coord
```

### Версия с картой (этот репозиторий)

Построение карты (`--map`) и исправления пакетного режима есть только в этом репозитории, в пакете из PyPI их нет.
Установка из исходного кода:

```bash
# в каталоге репозитория
pip install ".[png]"   # или `pip install .`, если схема в png не нужна
rosreestr2coord -v     # 5.3.3+map.1
```

## Для разработки (Development)

Для установки девелоперской версии и настройки среды разработки:

```bash
git clone https://github.com/rendrom/rosreestr2coord
cd rosreestr2coord
```

Установка через виртуальное окружение

```bash
# создание виртуального окружения
python -m venv ./env
# активация виртуального окружения для Linux и MacOS
. ./env/bin/activate
# активация виртуального окружения для Windows
. ./env/Scripts/activate
# установка пакета в режиме редактируемой установки
pip install -e .
pip install -e .[dev]
```

Это позволит вам вносить изменения в код и сразу же тестировать их.

## Использование

### Из консоли

После установки `rosreestr2coord` вы можете запускать его прямо из командной строки. Вот основные способы использования:

#### 1. Получение координат по кадастровому номеру

```bash
rosreestr2coord -c 38:06:144003:4723
```

#### 2. Пакетная обработка из списка кадастровых номеров

```bash
rosreestr2coord -l ./cadastral_numbers_list.txt
```

Для пакетной обработки используйте файл с перечислением кадастровых номеров (каждый номер на новой строке).
Допускаются пустые строки, комментарии после `#` и несколько номеров в одной строке (через запятую, точку с запятой или пробел).

Результаты пакетной обработки:

- `output/geojson/<номер>.geojson` — каждый найденный объект;
- `output/geojson/<имя списка>.geojson` — все найденные объекты одним файлом;
- `output/csv/<имя списка>.csv` — отчёт: строка на каждый номер списка, в том числе на те, по которым ничего не получено.

Повторный запуск той же команды не запрашивает объекты, которые уже сохранены в `output/geojson` (ключ `-r` — запросить всё заново).
После отказа в доступе (HTTP 403) или трёх неудачных запросов подряд обработка останавливается, чтобы не продлевать блокировку;
оставшиеся номера получают состояние `skipped`, а при следующем запуске обработка продолжается с них.

#### 3. Карта по списку кадастровых номеров

```bash
rosreestr2coord -l ./cadastral_numbers_list.txt --map
```

Ключ `-m` (`--map`) после загрузки строит карту всех объектов списка:

- `output/map/<имя списка>.html` — интерактивная карта в одном файле. Открывается в любом браузере, ничего устанавливать не нужно.
  Подложка (спутниковый снимок, OpenStreetMap или OpenTopoMap) загружается из интернета; без интернета границы показываются без подложки.
- `output/map/<имя списка>.png` — обзорная схема с нумерацией объектов и таблицей. Создаётся, если установлен `matplotlib` (`pip install matplotlib`).

На карте есть каждый номер списка, в том числе те, по которым границы получить не удалось. Состояние номера указано в списке рядом с картой
и в столбце `status` отчёта csv:

| status | Что это значит |
| --- | --- |
| `ok` | объект найден, границы получены |
| `no_bounds` | объект есть в реестре, но границ у него нет (на карте — точка, если сервис её вернул) |
| `not_found` | сервис ответил, что объекта с таким номером нет |
| `error` | запрос не выполнен (нет связи, отказ в доступе, ошибка сервера): об объекте ничего не известно |
| `skipped` | запрос не отправлялся: обработка списка была остановлена |

Дополнительно:

- `-d` (`--display`) — сразу открыть карту в браузере;
- `--title "Мои участки"` — заголовок карты;
- `--map-from output/geojson` — построить карту из уже сохранённых файлов GeoJSON, без обращения к сервису
  (вместе с `-l` на карте будут только номера списка, в порядке списка). Ключ `-m` работает и с одним номером: `rosreestr2coord -c 38:06:144003:4723 -m`.

Границы на карте — это то, что публикует геопортал НСПД; карта служит для ориентирования и не заменяет выписку из ЕГРН.

#### Доступ к НСПД

По сообщениям пользователей, nspd.gov.ru отвечает только на запросы с российских IP-адресов и блокирует слишком частые запросы (ответ `403 Forbidden`).
Из-за рубежа нужен VPN с российским адресом или HTTP-прокси: `--proxy_url 'http://user:password@12.345.67.89:9876'` (SOCKS-прокси не поддерживается).
Между запросами списка выдерживается пауза (`-D`, по умолчанию 1 секунда).

#### Рекомендации по использованию

- **Рабочая директория**: При выполнении скрипта в текущей директории будут создаваться различные файлы и папки. Рекомендуется создать отдельную директорию для работы с приложением, чтобы избежать захламления основной рабочей области.

- **Параметры командной строки**:

- -h - справка
- -c - кадастровый номер
- -p - путь для промежуточных файлов
- -o - путь для полученного geojson файла
- -t - тип площади:
  - 1 Объекты недвижимости
    - Земельные участки ЕГРН
    - Здания
    - Сооружения ЕГРН
    - Объекты незавершённого строительства
    - Единые недвижимые комплексы
    - Предприятия как имущественным комплексы
  - 2 Кадастровое деление
    - Кадастровые округа
    - Кадастровые районы
    - Кадастровые кварталы
  - 4  Административно-территориальное деление
    - Муниципальные образования
    - Населённые пункты
  - 5  Зоны и территории
    - Территории объектов культурного наследия
    - Зоны с особыми условиями использования территории
    - Особо охраняемые природные территории
    - Охотничьи угодья
    - Лесничества, Особые экономические зоны
    - Территории опережающего развития
  - 7  - Территориальные зоны
  - 15 - Комплексы объектов
    - Единые недвижимые комплексы
    - Предприятия как имущественным комплексы
- -l - пакетная загрузка из списка в текстовом файле ( `rosreestr2coord -l list_example.txt` )
- -m, --map - построить карту результата: интерактивную страницу html и схему png
- --map-from - построить карту из сохранённых файлов geojson (файлы или каталоги), без запросов к сервису
- --title - заголовок карты
- -d, --display - открыть карту в браузере (включает `--map`)
- -D, --delay - пауза между запросами при пакетной загрузке, в секундах (по умолчанию 1)
- -T, --timeout - время ожидания ответа, в секундах (по умолчанию 5)
- -r - не использовать кэширование
- -P - загрузка через прокси
- -v - показать версию
- -u - установить адрес прокси (например, `--proxy_url 'http://user:password@12.345.67.89:9876'`)

### Программное использование

`rosreestr2coord` можно также использовать как библиотеку в вашем Python проекте. Ниже приведен пример использования и описание основных функций и параметров.

```python
from rosreestr2coord import Area

# Создание объекта Area с кадастровым номером участка
area = Area("38:06:144003:4723")

# Преобразование данных в формат GeoJSON
area.to_geojson()
```

После запроса у объекта `Area` заполнены `status` (`ok`, `no_bounds`, `not_found`, `error`), `has_bounds` и `error_message`.

Карта по списку номеров:

```python
from rosreestr2coord.batch import batch_parser
from rosreestr2coord.visualize import write_html, write_png

results = batch_parser(["38:06:144003:4723", "38:36:000021:1106"], output="output", file_name="mylist")
write_html("output/map/mylist.html", results, title="Мои участки")
write_png("output/map/mylist.png", results, title="Мои участки")  # нужен matplotlib
```

#### Параметры конструктора Area

- code: Кадастровый номер участка.
- area_type: Тип площади.
- media_path: Путь для временных файлов.
- with_log: Включение логирования действий.
- coord_out: Формат вывода координат (например, 'EPSG:4326').
- center_only: Если True, экспортируются только координаты центров участков.
- with_proxy: Если True, запросы отправляются через прокси-сервер.
- use_cache: Если True, используется кэширование запросов.
- proxy_url: Адрес прокси-сервера.
